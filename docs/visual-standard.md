# Estándar visual
Identidad neutral, sin marca de organismo ni empresa. Azul profundo #11253B, verde acento #55D6BE, fondo blanco y texto #17283A. No usar solo color para comunicar estados. Usar títulos jerárquicos, tablas con unidades, diagramas legibles, enlaces relativos y texto alternativo. En Excel: separar datos originales, transformación y resultados, aplicar filtros y formatos adecuados; no confundir formato con validación. En gráficos: ejes, unidades, períodos, fuente y escalas honestas. El banner SVG es un recurso original del repositorio, no una acreditación institucional.
