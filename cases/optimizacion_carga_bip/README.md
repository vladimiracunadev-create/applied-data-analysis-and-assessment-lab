# P20 · Optimización exploratoria de estudios para carga bip!

P20 toma las diez celdas candidatas de P16 y compara todas las carteras factibles para
presupuestos de uno a cinco estudios. Maximiza el puntaje exploratorio heredado y exige
representar `min(presupuesto, 3)` bandas relativas de latitud.

La salida **no recomienda construir un punto de carga**. Las bandas no son divisiones
oficiales, el presupuesto no está expresado en dinero y faltan demanda, transacciones,
costos, predios, seguridad y red peatonal. Es una herramienta transparente para decidir
qué estudios de factibilidad iniciar primero.
